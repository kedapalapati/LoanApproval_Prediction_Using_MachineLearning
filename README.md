# LoanApproval_Prediction_Using_MachineLearning
This project implements machine learning models to historical loan applications data to determine likely outcomes of loan approvals. The pipeline built with PySpark MLlib in Databricks platform uses Logistic Regression and Decision Tree Classifier to find crucial predictors which lead to loan approval making decisions automated and fair. Below is the Databricks Notebook linked below contains complete project details: [Databricks URL](https://databricks-prod-cloudfront.cloud.databricks.com/public/4027ec902e239c93eaaa8714f173bcfc/567573318709407/3065080031960545/7836163358693037/latest.html)
